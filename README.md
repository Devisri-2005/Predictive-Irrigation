# Predictive-Irrigation

## AI-Enhanced IoT-Based Predictive Irrigation System Using Multi-Source Environmental and Soil Data

### Project Overview

This project aims to develop an AI-enhanced IoT-based predictive irrigation system that combines environmental, soil, and real-time sensor data to predict soil-moisture conditions and support intelligent irrigation decisions.

The system is designed to move beyond fixed soil-moisture threshold-based irrigation by using historical environmental and soil data along with machine learning.

### Current Progress

The software development phase has been completed to the current stage.

- Data collection and organization
- Data preprocessing and cleaning
- Environmental and soil data preparation
- Data integration and merging
- Machine learning pipeline development using Google Colab
- Model prediction and evaluation

### Data Sources

The project uses multiple sources of environmental and soil information, including:

- NASA POWER environmental data
- SMAP soil-moisture data
- SoilGrids soil data
- Environmental and soil-related features
